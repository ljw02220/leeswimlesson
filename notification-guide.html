알림 설정 방법

운동량과 수업 댓글 소식을 휴대폰으로 받아보세요.

leeswimlesson.kro.kr
  1. Safari에서 사이트 열기

    카카오톡 안의 브라우저 대신 Safari로 위 주소를 열어주세요.

  2. 공유 → 홈 화면에 추가

    공유 메뉴에서 ‘홈 화면에 추가’를 선택해요. ‘웹 앱으로 열기’가 보이면 켜고 ‘추가’를 눌러요.

  3. 홈 화면의 수영관리 아이콘으로 열기

    새로 추가된 아이콘을 눌러 실행한 뒤 로그인해주세요.

  4. 종 모양 → 휴대폰 알림 ‘켜기’

    화면 상단 알림 아이콘을 누르고 ‘켜기’를 눌러요. 권한 창이 나오면 ‘허용’을 선택해주세요.

  5. 테스트 알림 보내기

    ‘내 기기로 테스트 알림 보내기’를 눌러 배너가 오는지 확인해요. 앱을 닫을 필요는 없어요.

알림이나 소리가 안 나오나요?

아이폰 설정 → 알림 → 수영관리에서 알림 허용·사운드·배너·잠금 화면을 확인해주세요.

무음 모드·집중 모드가 켜져 있으면 소리가 안 날 수 있어요.

  1. Chrome에서 사이트 열기

    카카오톡 안의 브라우저 대신 Chrome으로 위 주소를 열어주세요.

  2. 오른쪽 위 메뉴 → 설치

    ‘설치 및 바로가기 만들기’ → ‘설치’를 눌러요. 기기에 따라 ‘홈 화면에 추가’ 또는 ‘앱 설치’로 보여요.

  3. 홈 화면의 수영관리 아이콘으로 열기

    추가된 아이콘을 눌러 실행한 뒤 로그인해주세요.

  4. 종 모양 → 휴대폰 알림 ‘켜기’

    화면 상단 알림 아이콘을 누르고 ‘켜기’를 눌러요. 권한 창이 나오면 ‘허용’을 선택해주세요.

  5. 테스트 알림 보내기

    ‘내 기기로 테스트 알림 보내기’를 눌러 배너가 오는지 확인해요. 앱을 닫을 필요는 없어요.

알림이나 소리가 안 나오나요?

휴대폰 설정 → 알림에서 수영관리 또는 Chrome의 알림을 허용해주세요.

Chrome → 설정 → 사이트 설정 → 알림과 무음·방해 금지 모드도 확인해주세요.

참고: Google의 웹앱 설치 안내

기기마다 한 번씩 설정해주세요. 메뉴 이름은 기기·버전에 따라 다를 수 있어요. 최신 버튼이 안 보이면 웹앱 상단의 ↻ 새로고침을 눌러주세요.
